# غرفة القياس الافتراضية

العميل يختار **شخص افتراضي** (صورة واقعية لشخص ما هو موجود في الحقيقة) أو يرفع **صورته**، ويختار قطع من المتجر،
والموقع يولّد له صورة حقيقية للتنسيق من زاويتين بـ **Nano Banana 2** من Google (Gemini 3.1 Flash Image).
OpenAI موجود كبديل من الإعدادات.

## التشغيل

يحتاج Node.js 18 أو أحدث، وما يحتاج أي مكتبات إضافية.

```bash
cd virtual-fitting-room
cp .env.example .env        # حط مفتاح GEMINI_API_KEY وكلمة مرور التاجر
node server.js --generate-models   # مرة وحدة: يولّد صور الموديلات الافتراضية
node server.js                      # افتح http://localhost:3000
```

بدون مفتاح يشتغل الموقع بـ**وضع العرض** ويعرض أمثلة جاهزة.

## وش يصير عند «ولّد الإطلالة»

1. السيرفر ياخذ صورة الشخص (الموديل أو صورة العميل) وصور القطع المختارة من `products/`.
2. يبني الوصف تلقائياً من `prompt.js` ووصف كل منتج (الحقل `ai` في `catalog.json`).
3. يرسلها لـ Gemini API (`models/gemini-3.1-flash-image-preview:generateContent`) بدقة 2K ونسبة 3:4، ويطلع الصورة الأمامية.
4. يرسل الصورة الأمامية مرة ثانية ويطلب نفس الشخص ونفس اللبس بوقفة جانبية.
5. نتائج الموديلات الافتراضية تنحفظ في `data/cache/`، فنفس التنسيق ما يتولد مرتين. صور العملاء ما تنحفظ.

## الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | واجهة العميل ولوحة التاجر |
| `server.js` | السيرفر والربط مع Google Gemini (أو OpenAI) |
| `prompt.js` | صياغة الطلب للذكاء الاصطناعي (مشتركة بين الواجهة والسيرفر) |
| `catalog.json` | المنتجات والموديلات الافتراضية |
| `products/` | صور المنتجات بعد إزالة الخلفية |
| `data/` | يتولد تلقائياً: صور الموديلات، منتجات التاجر، الكاش (مو داخل git) |

## إضافة منتج

من «لوحة التاجر» في الموقع (تحتاج `OWNER_PASSWORD`)، أو بإضافته في `catalog.json` مع صورته في `products/`.
الوصف الإنجليزي في حقل `ai` يفرق كثير في دقة النتيجة: اكتب اللون والقصّة والطباعة ومكان الشعار.

## مفتاح Gemini

1. ادخل [Google AI Studio](https://aistudio.google.com) وسوّ **Get API key**.
2. فعّل الفوترة على المشروع (Nano Banana 2 ما يشتغل على الباقة المجانية).
3. حط المفتاح في `.env` بالشكل: `GEMINI_API_KEY=...`

لا ترفع ملف `.env` لأي مكان، وهو مستثنى من git.
